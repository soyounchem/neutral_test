# 중화 실험실

0.1 M HCl과 0.1 M NaOH의 2/10, 4/8, 6/6, 8/4 mL 조합을 비교하는 한국어 웹 시뮬레이션입니다. 외부 라이브러리나 외부 네트워크 없이 동작합니다.

## 실행

Python 3이 있는 환경에서 저장소 루트에서 `npm start` 또는 `python3 -m http.server 3000 --bind 0.0.0.0`을 실행하고 브라우저로 3000번 포트에 접속합니다. JavaScript 모듈을 사용하므로 HTML을 파일로 직접 여는 대신 HTTP 서버를 사용하세요. 의존성 설치나 빌드는 필요 없습니다.

## 검증

Node.js 18 이상에서 `npm test`를 실행합니다. 제한 반응물, 물질량 보존, 열량, 당량점, pH와 초기 온도 영향을 검증합니다.

브라우저 회귀 검증은 Python Playwright와 `/usr/bin/chromium`이 설치된 환경에서 `python3 tests/browser_smoke.py`로 실행할 수 있습니다. 저장소 루트에서 실행하며 로컬 3000번 포트가 비어 있어야 합니다. 네 조합 자동 시작·재실행·빠른 전환·초기화·모바일 표시를 확인합니다.

## 과학적 가정

두 용액은 완전 해리하는 강산과 강염기이며 초기 온도는 같습니다. H⁺ + OH⁻ → H₂O, 중화열 −57.3 kJ/mol, 밀도 1.00 g/mL, 비열 4.18 J/(g·°C)를 적용합니다. Q = 반응 몰수 × 57,300 J/mol, ΔT = Q/(질량 × 비열)로 계산합니다. 용기 열용량, 외부 열손실, 혼합 및 희석열은 무시합니다.

기본 22 °C에서 예상 온도 상승은 순서대로 약 0.23, 0.46, 0.69, 0.46 °C입니다. 실제 온도계 측정값은 이론값과 다를 수 있습니다. pH는 pKw = 14인 25 °C 기준 근삿값입니다. 그래프의 가로축은 혼합 진행도이며 시간/실제 반응속도를 나타내지 않습니다. 입자 모형은 생성된 물만 표시하며 용매 물 분자는 생략합니다. 비교표는 완료 후 예측값, 관찰 패널은 현재 반응 진행 상태를 표시합니다.

## 조합 전환과 학교 표시

부피 조합 버튼을 누르면 진행 중인 반응을 취소하고 선택한 조합으로 즉시 새 반응을 시작합니다. 초기화 및 초기 온도 변경은 혼합 전 상태로 돌아갑니다. 반응 이온은 서로 접근하여 H₂O로 바뀌고, 과량 이온과 구경꾼 이온은 유지됩니다.

상단의 신림고등학교 표시는 학교명을 사용한 텍스트 워드마크입니다. 공식 교표 이미지가 아니며, 공식 원본은 아직 포함되지 않았습니다. 학교 홈페이지는 현재 환경의 네트워크 정책으로 접근이 제한되어 원본을 확인하지 못했습니다.
